## Project files

One Markdown file per project in this folder. Each starts with a small
header block (area, status, updated), then: Goal, Context, Workstreams with
tasks, Open questions for Art, Log.

Task owner labels:

- `[art]` only Art can do it
- `[claude]` Claude can do it alone (research, drafting, scheduling)
- `[claude?]` Claude can do it after Art answers a question
